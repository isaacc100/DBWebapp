Quick Setup

  1. Create a D1 database: wrangler d1 create dbwebapp
  2. Add the database ID to worker/wrangler.toml
  3. Apply the schema: wrangler d1 execute dbwebapp --file=schema.sql
  4. Start the worker: cd worker && wrangler dev
  5. Open SQL Playground and start querying!
